# 应用数据同步

入口：**设置 → 应用 → 数据同步**。填写 WebDAV 目录 URL、用户名和密码；URL 中的目录大小写应与服务端一致。可先使用“测试连接”检查目录访问权限。

应用数据包含设置、收藏、历史、Cookie 和漫画源文件等，不包含本地漫画图片。漫画归档备份和 WebDAV 在线漫画库分别配置。

应用数据同步恢复使用 v1.17.0 的 WebDAV SDK 传输流程，包括服务提供的下载重定向链接（例如 123 云盘的下载域名）。远端备份沿用“日期-数据版本.venera”文件名；上传前按旧版规则清理同日备份及达到数量上限时的最旧备份，不要求服务端提供强 ETag 或条件写入支持。

## 同步模式

| 模式 | 触发方式 |
|---|---|
| 手动同步 | 只在点击主页同步卡片的上传、下载按钮时传输 |
| 实时同步 | 本地数据变更时上传，启动和恢复前台时检查远端；恢复检查至少间隔 10 分钟 |
| 定时同步 | 按 5、15、30、60、180 或 360 分钟间隔同步，默认 30 分钟 |

定时同步将间隔内的多次本地修改合并：有待同步修改时上传，没有修改时检查远端版本，只在有新版时下载。上传过程中产生的新修改保留到下一轮；失败后保留待同步状态，在下个间隔重试。

定时器只在应用进程运行期间工作，应用关闭后不会唤醒系统。待上传状态和上次尝试时间保存在当前设备，重新打开或恢复前台时补做已到期同步；未到期则继续等待。移动系统暂停后台进程时，不能保证准点同步。

主页的上传、下载按钮在三种模式下均可立即操作，手动操作后从本次完成时间重新计算间隔。主动下载会按现有数据导入规则应用远端快照；有本地未上传修改时，先确认要保留哪台设备的数据。同步不是多设备同时编辑的冲突合并工具。

## 保存配置

选择实时或定时模式后，指定首次上传或下载并点击“继续”。首次操作成功才保存配置；失败会恢复原目录、模式、间隔和排除字段。选择手动模式时，“继续”只保存配置。

修改模式或间隔会重新安排下一次同步。清空 URL、用户名和密码后保存可断开同步。旧版自动同步开启时对应实时模式，关闭时对应手动模式；升级不会自动改为定时同步。

跳过设置字段仅影响所列字段；同步模式、间隔和 WebDAV 连接信息本来就保存在当前设备，不会被另一台设备覆盖。

## 升级后的首次同步

恢复 v1.17.0 方案后，自动同步直接使用本机待上传标记和远端数据版本，不再要求 RC 版的内容基线，也不会因为旧的 `Complete an upload or download a newer backup to resume automatic sync.` 提示阻断传输。RC 版已有上传／内容基线恢复记录及操作标记保留在本机，不由这套稳定同步流程读取、删除或回放；本地数据导入的中断恢复仍沿用现有实现。

升级前请导出本机备份，再覆盖安装，不要清空应用数据或删除恢复文件。与 v1.17.0 一样，有本机待同步修改时上传，否则检查并下载更新的数据；同步不合并多设备同时编辑，也不提供 RC 版条件写入／删除的并发保护。
